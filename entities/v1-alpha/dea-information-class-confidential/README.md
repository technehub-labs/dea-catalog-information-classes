# Confidential

Information whose disclosure causes material harm to the enterprise. Access is granted on a need-to-know basis and requires the information owner's approval.

## Classification
- **Sensitivity:** confidential
- **Regulatory regime:** none

## Handling requirements
- Access on need-to-know, approved by the information owner.
- Encryption in transit and at rest.
- Disclosure events are logged and reviewed.

## Retention
Per the enterprise records-retention schedule; legal-hold overrides destruction.
